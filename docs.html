API Reference
Base URL: /api  ·   All requests and responses use JSON unless otherwise noted.  ·   Protected routes require a valid token cookie, issued at login.
Authentication
POST /api/auth/register Create a new account ▶
Creates a new player account, hashes the provided password with bcrypt, and sets a signed JWT cookie valid for 7 days.
Request Body
FieldTypeRequiredDescription
emailstringYesUnique email address for the account.
passwordstringYesPlain-text password. Hashed with bcrypt before storage.
usernamestringNoDisplay name. Defaults to the local part of the email address.
Example Request
fetch("/api/auth/register", {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    email: "player@example.com",
    password: "securePassword1",
    username: "PlayerOne"
  })
})
Response 200
{
  "id": "64a1b2c3d4e5f6a7b8c9d0e1",
  "email": "player@example.com",
  "username": "PlayerOne",
  "isAdmin": false,
  "pfpUrl": null
}
Errors
StatusMessage
400Need both email AND password, come on!
400That email's already taken, snooze you lose!

POST /api/auth/me/pfp Upload profile picture Auth ▶
Accepts multipart/form-data. Uploads the image to Cloudinary and crops it to 256x256 pixels using face-gravity cropping.
Form Fields
FieldTypeConstraints
pfpfileAccepted formats: jpg, jpeg, png, gif, webp. Maximum size: 2 MB.
Example Request
const formData = new FormData()
formData.append("pfp", fileInput.files[0])

fetch("/api/auth/me/pfp", {
  method: "POST",
  credentials: "include",
  body: formData
})
Response 200
{
  "id": "64a1b2c3d4e5f6a7b8c9d0e1",
  "email": "player@example.com",
  "username": "PlayerOne",
  "isAdmin": false,
  "pfpUrl": "https://res.cloudinary.com/demo/image/upload/v1/64a1b2c3d4e5f6a7b8c9d0e1"
}
Errors
StatusMessage
400You forgot to attach a file?
400Images only! (jpeg, png, gif, webp)
400File too large (max 2 MB)

POST /api/auth/reset-by-username Reset password ▶
Resets a player's password by matching both the provided username and email address against existing account records.
Request Body
FieldTypeRequiredDescription
usernamestringYesThe account's current display name.
emailstringYesThe email address associated with the account.
passwordstringYesThe new password to set. Minimum 6 characters.
Example Request
fetch("/api/auth/reset-by-username", {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    username: "PlayerOne",
    email: "player@example.com",
    password: "newPassword123"
  })
})
Response 200
{ "message": "Password changed! Go log in!" }
Errors
StatusMessage
400Need username, email AND a new password for this!
400Password needs to be at least 6 chars, come on!
404No one matching that username + email combo!
Scores
POST /api/scores Save a game score Auth ▶
Records a completed game score for the authenticated player.
Request Body
FieldTypeRequiredDescription
scorenumberYesFinal numeric score for the game.
wordsusednumberYesTotal number of words entered during the game.
maxcombonumberYesHighest consecutive combo reached.
Example Request
fetch("/api/scores", {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    score: 2400,
    wordsused: 18,
    maxcombo: 7
  })
})
Response 200
{
  "_id": "64b9c1d2e3f4a5b6c7d8e9f0",
  "userId": "64a1b2c3d4e5f6a7b8c9d0e1",
  "username": "PlayerOne",
  "score": 2400,
  "wordsused": 18,
  "maxcombo": 7,
  "createdAt": "2024-11-15T14:32:00.000Z"
}

POST /api/scores/trigram Log a trigram attempt Auth ▶
Records a single trigram attempt for the authenticated player, regardless of whether the attempt was successful.
Request Body
FieldTypeRequiredDescription
trigramstringYesThe 3-letter sequence that was presented.
solvedbooleanYesWhether the player submitted a valid word before time expired.
wordlengthnumber | nullNoCharacter length of the submitted word. Null if unsolved.
timetakennumber | nullNoSeconds elapsed before submission. Null if unsolved.
Example Request
fetch("/api/scores/trigram", {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    trigram: "ack",
    solved: true,
    wordlength: 7,
    timetaken: 3.41
  })
})
Response 200
{
  "_id": "64c7d8e9f0a1b2c3d4e5f6a7",
  "userId": "64a1b2c3d4e5f6a7b8c9d0e1",
  "trigram": "ack",
  "solved": true,
  "wordlength": 7,
  "timetaken": 3.41,
  "createdAt": "2024-11-15T14:32:05.000Z"
}

POST /api/admin/scores Create a score entry Admin ▶
Creates a new score record. If the provided username matches an existing account, the record is linked to that user's ID.
Request Body
FieldTypeRequired
usernamestringYes
scorenumberYes
wordsusednumberYes
maxcombonumberYes
Validation: wordsused must be greater than or equal to maxcombo, and score must be greater than or equal to 100 x wordsused.
Example Request
fetch("/api/admin/scores", {
  method: "POST",
  credentials: "include",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({
    username: "PlayerOne",
    score: 2400,
    wordsused: 18,
    maxcombo: 7
  })
})
Response 200
{
  "id": "64b9c1d2e3f4a5b6c7d8e9f0",
  "username": "PlayerOne",
  "score": 2400,
  "wordsused": 18,
  "maxcombo": 7,
  "createdAt": "2024-11-15T14:32:00.000Z"
}
Errors
StatusMessage
400Validation error message describing the constraint that was violated.
